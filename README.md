# Garland ブログ自動下書きシステム

Garland（https://garland-hair.jp）のNEWSに、SEO・AI検索向けの記事を**下書きとして**自動で作るプログラムです。
公開・更新・削除は一切しません。公開は管理者が管理画面で確認してから行います。

## 動き方
- 日本時間の **月・水・金の朝7時ごろ** に1本ずつ（週3本）、WordPressの「お知らせ」に下書きを作ります。
- テーマは `data/topic_ledger.json` の上から順に使います。既存記事と似たタイトルは自動でスキップします。
- 写真は、WordPressのメディアの「説明」欄に **`掲載OK`** と書かれた写真だけを使います（店舗名が書かれた写真を優先）。
- 店舗の住所・電話・予約ボタンは `config/stores.json` からプログラムが入れます（AIには書かせません）。
- 料金・誇大表現・許可していないリンクなどが入っていたら保存しません。

## 下書きができたら（管理者の作業）
1. 管理画面の「お知らせ」→ 下書きを開いて、内容とスマホでの見え方を確認
2. 必要なら文章を直す
3. 右側の「公開」の横の「編集」で日時を選ぶと **予約公開**、そのまま押すと即公開

## 安全装置
| 仕組み | 内容 |
|---|---|
| 権限 | 投稿ユーザーは「寄稿者」。管理者・編集者の権限だと自動で停止 |
| 重複防止 | 同じ日の2回目は実行しない／同時に2つ動かない／既存記事と似たタイトルは使わない |
| 料金上限 | `config/settings.json` の `monthly_budget_usd`（初期値 $5/月）に達したら停止 |
| ログ | `logs/年-月.jsonl` に毎回の記録。GitHubの「Actions」画面でも確認可 |
| エラー通知 | 失敗するとGitHubから登録メールアドレスにメールが届きます |

## パスワード類（GitHubの Settings → Secrets and variables → Actions）
| 名前 | 中身 |
|---|---|
| `WP_USER` | `auto-writer` |
| `WP_APP_PASSWORD` | auto-writer のアプリケーションパスワード（GitHub専用に発行） |
| `ANTHROPIC_API_KEY` | AIのAPIキー |

コードやファイルには絶対に書かないでください。

## 手動で試す
GitHubの「Actions」→「ブログ下書きの自動作成」→「Run workflow」
- `dry-run`：WordPressには保存せず、プレビューだけ作る（Artifactsの preview をダウンロード）
- `draft`：実際に下書きを1本作る

## 止めたいとき
「Actions」→「ブログ下書きの自動作成」→ 右上の「…」→「Disable workflow」
